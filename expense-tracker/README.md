# Expense Tracker

A responsive expense tracker built with vanilla HTML, CSS, and JavaScript.

## Features
- Income and expense transactions
- Balance, total income, and total expense
- Category-based spending bars
- Transaction filtering
- Delete individual transactions
- Clear all transactions
- Light/dark theme toggle
- Responsive layout
- Indian Rupee (₹) formatting

## Structure
- `index.html` — page structure
- `css/style.css` — styling and responsive layout
- `js/app.js` — transaction, filter, chart, theme, and render logic

## Run
Open `index.html` directly or use VS Code Live Server.
