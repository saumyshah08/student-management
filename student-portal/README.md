# Student Management Portal

## Pages
- dashboard/dashboard.html + dashboard.css + dashboard.js
- schedule/schedule.html + schedule.css + schedule.js
- analytics/analytics.html + analytics.css + analytics.js
- directory/directory.html + directory.css + directory.js

## Run
Open `dashboard/dashboard.html` in a browser.

All pages are linked to each other. Demo state uses localStorage so attendance, tasks and dark mode persist between pages.

No backend or Node.js is required for this frontend demo.
